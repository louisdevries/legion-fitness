💪 Legion Fitness

Legion Fitness is a modern fitness tracking and training platform built to deliver structured workout programs, progress tracking, and an engaging exercise experience. The app combines personalized training programs with superset logic, alternative exercises, and performance tracking to help users stay consistent and improve over time.

🚀 Features
🏋️ Training System
Structured multi-week fitness programs (1, 3, or 5 program access model)
6-week progressive workout cycles
Day-by-day exercise scheduling
🔁 Advanced Exercise Logic
Supersets (back-to-back exercises with no rest)
Alternative exercises with dynamic switching
Set-based or duration-based exercises
Support for reps, time, or distance-based tracking
📊 Progress Tracking
Exercise completion logging per set
Weight and health tracking
Progress history over time
Workout consistency monitoring
🎮 User Experience
Clean, mobile-first interface
Swiper-based exercise navigation
Media support for exercises (images/videos)
Admin-controlled program creation system
🧱 Tech Stack
Backend: Flask (Python)
Database: PostgreSQL (Supabase)
Frontend: Jinja Templates + Bootstrap 5
Mobile App: Flutter (exercise runner + tracking features)
Realtime / Sync: Supabase API integration
🗂️ Database Overview

Core tables include:

users
fitness_programs
program_exercises
program_exercise_details
exercise_categories
exercise_supersets
exercise_alternatives
progress_logs
weight_logs
health_profiles
📱 App Highlights
Adaptive workout runner with real-time exercise flow
Smart superset detection and handling
Alternative exercise fallback system
Admin tools for program creation and editing
Fitness progression visualization and logging
🧠 Concept

Legion Fitness is designed around one idea:

Training should feel structured, adaptive, and progressive — not random or repetitive.

The system ensures users always have:

Clear direction
Scalable difficulty
Built-in variation to prevent plateaus
