# Legion Fitness 💪

Legion Fitness is a structured fitness training platform designed to deliver progressive workout programs, track user performance, and provide an adaptive training experience. It combines program-based training, advanced exercise logic, and progress tracking into one system.

---

## 🚀 Features

### 🏋️ Training System
- Multi-week structured workout programs (1, 3, or 5 program access model)
- 6-week progressive training cycles
- Day-based workout scheduling

### 🔁 Exercise Logic
- Superset support (back-to-back exercises without rest)
- Alternative exercises with switching functionality
- Reps, time, and distance-based tracking
- Flexible exercise configurations per program

### 📊 Progress Tracking
- Exercise completion tracking per set
- Weight and health logs
- Historical workout progress tracking
- Consistency monitoring

### 🎮 User Experience
- Mobile-first responsive interface
- Swiper-based exercise flow
- Media support for exercises (images/videos)
- Admin system for program creation and management

---

## 🧱 Tech Stack

- **Backend:** Flask (Python)
- **Frontend:** HTML, Bootstrap 5, Jinja2
- **Database:** PostgreSQL (Supabase)
- **Mobile App:** Flutter
- **State / API:** Supabase integration

---

## 🗂️ Database Structure

Key tables:
- users  
- fitness_programs  
- program_exercises  
- program_exercise_details  
- exercise_categories  
- exercise_supersets  
- exercise_alternatives  
- progress_logs  
- weight_logs  
- health_profiles  

---

## 📱 Application Overview

Legion Fitness focuses on delivering structured and adaptive training:

- Guided workout flow per program
- Smart superset handling
- Alternative exercise fallback system
- Exercise media and instructions
- Progress tracking across workouts

---

## 🧠 Concept

The goal of Legion Fitness is:

> To make fitness training structured, adaptive, and progressive instead of random and inconsistent.
